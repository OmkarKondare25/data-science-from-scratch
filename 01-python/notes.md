# Python foundations

## Key ideas (in my own words)

- single line comments contains ##  and multine comments contains ''' .... '''
- multiline comments only works in .py files
- Python is case sensitive
- python uses indentation to define blocks of code (4 spaces or tab)
- \ is used for line continuation
- we can use multiple statement in a singlr line using ;
- Python is Dynamically Typed, we dont need to specify the data type of a variable, python understands itself at the time of runtime which datatype is the variable it is called as Type Inference
- Variables have to start with letter or underscore, variables can contain letters,numbers,underscores
- Python allows the type of variable to change as the code executes for eg var = 25 , var = 'omkar'
- Data types are basically classification of data which tells the compiler or interpreter how the programmer intends to use the data
- Different data type takes different amounts of memory to store
- difference between division (/) and floor division (//) is division gives float value for eg 5.0 and floor divisions give int value for eg 5
